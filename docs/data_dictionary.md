# Data Dictionary

## Global conventions
- Dates: `YYYY-MM-DD`. Timestamps: ISO 8601 UTC, e.g. `2026-03-15T08:15:30`.
- Simulation window: 2026-01-01 to 2026-12-31. Seed: 20261022.
- IDs are immutable, zero-padded, and generated by one function (src/ids.py).
- Booleans are stored as `true`/`false`.
- All data is synthetic. No personal data. Operator IDs are fake codes.
- Foreign keys (FK) must point to an existing row in the parent table.

## 5. CalibrationEvent
| Field | Type | Req | Allowed values / format | Unit | Unique | Validation rule |
|---|---|---|---|---|---|---|
| calibration_id | string | Y | `CAL-AST-000001-2026-000001` | - | Y | Matches `^CAL-AST-\d{6}-2026-\d{6}$`; the AST part equals asset_id |
| asset_id | string | Y | FK -> Asset | - | N | Must exist |
| plan_id | string | Y | FK -> CalibrationPlan | - | N | Must equal the asset's plan_id |
| supplier_id | string | Y | FK -> Supplier | - | N | Must exist |
| calibration_date | date | Y | in 2026 | - | N | Within simulation window |
| previous_due_date | date | Y | - | - | N | Always filled. For an asset's first 2026 event it is the due date inherited from pre-2026 history. Later events: the next_due_date of the latest PASS. |
| days_late | int | Y | >= 0 | days | N | max(0, calibration_date - previous_due_date) |
| measured_error | float | Y | any | instrument unit | N | Absolute error found |
| tolerance_applied | float | Y | > 0 | instrument unit | N | Must equal InstrumentType.tolerance |
| result | enum | Y | PASS, FAIL | - | N | PASS if abs(measured_error) <= tolerance_applied, else FAIL |
| next_due_date | date | Y | - | - | N | calibration_date + plan.interval_days (rule R1) |
| certificate_id | string | N | FK -> Certificate | - | Y | Empty only for certificate gaps |

## 8. ProductionUse
| Field | Type | Req | Allowed values / format | Unit | Unique | Validation rule |
|---|---|---|---|---|---|---|
| use_id | string | Y | `USE-AST-000001-20260315T081530` | - | Y | Matches the pattern; asset part equals asset_id; timestamp part equals used_at |

| exception_ref | string | N | FK -> AuditRecord | - | N | Required when OVERDUE_WITH_EXCEPTION |

## 11. GroundTruth (separate file: ground_truth.csv / ground_truth.json, never an input table)
| Field | Type | Req | Allowed values / format | Unit | Unique | Validation rule |
|---|---|---|---|---|---|---|
| anomaly_id | string | Y | `GT-0001` | - | Y | Matches `^GT-\d{4}$` |

| asset_id | string | Y | FK -> Asset | - | N | The asset the record truly belongs to |
| expected_decision | enum | Y | FLAG_AND_RECOMPUTE_DUE_DATE, FLAG_PROHIBITED_USE, REJECT_CERTIFICATE, CREATE_IMPACT_ASSESSMENT | - | N | Fixed by anomaly_type |
| reason | string | Y | free text | - | N | Explains why the record is wrong |
